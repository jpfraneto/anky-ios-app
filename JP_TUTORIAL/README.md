# JP Tutorial

This folder is the running teaching layer for the Anky iOS app.

The goal is not to teach Swift in the abstract. The goal is to teach Swift, SwiftUI, native iOS APIs, and app architecture through the real Anky codebase.

## How to use this folder

- Read lessons in order when possible.
- Jump to the lesson that matches the feature you are working on.
- Follow the file references back into the app code.
- Treat each lesson as a map of the real system, not as a generic tutorial.
